# Day 07 - Java Web3j RPC

## 学习目标

- 理解 Java 后端如何通过 `RPC（节点远程接口）` 读链
- 理解 `web3j（Java 链上交互库）` 的定位
- 能区分 `block（区块）`、`transaction（交易）`、`receipt（回执）`、`log（日志）`

## 核心概念

### 1. Web3j

web3j 是 Java 对链节点 JSON-RPC 的封装，常见用法包括：

- 查最新区块高度
- 查地址原生币余额
- 查交易回执
- 查事件日志

### 2. Receipt

交易回执是链上执行结果单，通常包含：

- 状态
- gas used
- 日志列表

### 3. Log

日志是执行后的结构化输出，是后端监听、索引和入账的重要输入。

## Java 后端映射

- web3j 类似外部服务 SDK
- receipt 像异步写操作的最终结果单

## 阶段结论

Day 7 的重点是：

**Java 后端接链的本质不是“查数据库”，而是“调节点”。**
