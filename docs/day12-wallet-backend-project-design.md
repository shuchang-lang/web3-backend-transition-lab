# Day 12 - Wallet Backend Project Design

## 学习目标

- 把前 11 天的内容收束成一个最小项目设计
- 明确模块边界、表结构和状态流转
- 为后续真正写代码做准备

## 最小项目目标

设计一个最小的钱包后端 demo，覆盖：

1. 充值地址管理
2. ERC-20 充值监听
3. 提现申请与状态流转
4. 内部账本与资金流水

## 建议模块

- 地址管理模块
- 充值监听模块
- 确认数处理模块
- 提现申请模块
- 广播与状态跟踪模块
- 账本模块

## 建议数据表

- `wallet_address`
- `deposit_record`
- `withdraw_order`
- `account_balance`
- `account_bill`

## 项目亮点

- 不只做链上监听，还做确认数入账闭环
- 不只做提现接口，还体现冻结、审核、回执跟踪和失败补偿
- 有内部账本和资金流水，而不是只维护一个余额字段

## 阶段结论

Day 12 的重点是：

**先把项目设计讲清楚，再进入实现，会比直接堆代码更稳。**
