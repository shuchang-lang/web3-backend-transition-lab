# Day 11 - Wallet Backend Architecture

## 学习目标

- 把充值和提现放到一套完整的钱包后端架构里理解
- 理解为什么必须有内部账本
- 理解钱包后端的公共底座能力

## 核心模块

- 地址管理
- 区块同步 / 日志监听
- 充值识别
- 提现申请
- 余额与账本
- 风控审核
- 交易构造与签名
- 状态跟踪
- 对账与补偿
- 审计与监控

## 核心观点

### 1. 链上余额不等于平台内部余额

平台内部还要管理：

- 可用余额
- 冻结余额
- 待确认充值
- 提现处理中金额

### 2. 充值和提现最终都会落到内部账本

所以钱包后端本质上是：

**链上交互系统 + 平台账务系统**

## 阶段结论

Day 11 的重点是：

**钱包后端的核心不是“收钱和打钱”，而是围绕统一账本维护账实一致。**
