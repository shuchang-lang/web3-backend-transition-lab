# Wallet Backend Module Design

## 设计目标

设计一个最小的钱包后端 demo，重点体现：

- 链上事件消费
- 内部账务处理
- 提现状态流转
- 幂等、确认数和补偿

## 模块划分

### 1. 地址管理模块

职责：

- 给用户分配充值地址
- 维护地址与用户映射
- 按链和币种管理地址

### 2. 区块同步模块

职责：

- 持续扫描新区块
- 保存同步进度
- 支持断点续跑

### 3. 日志解析模块

职责：

- 过滤目标合约
- 识别 Transfer 事件
- 解出 `from / to / amount`

### 4. 充值处理模块

职责：

- 生成待确认充值记录
- 检查确认数
- 触发正式入账

### 5. 提现处理模块

职责：

- 创建提现单
- 冻结余额
- 审核流转
- 广播链上交易
- 跟踪回执

### 6. 账本模块

职责：

- 管理可用余额与冻结余额
- 写资金流水
- 保证幂等

### 7. 对账与补偿模块

职责：

- 核对链上状态与内部账本
- 处理漏记、错记、卡单
- 定时重试失败任务

## 核心设计原则

1. 链上状态与平台账务分层
2. 充值和提现都围绕统一账本流转
3. 所有资金变化必须落流水
4. 所有关键状态都需要幂等控制
